## 📖 Descrizione

**ScoreBTW** è una piattaforma web dedicata agli appassionati di videogiochi che permette di scoprire, recensire e condividere opinioni sui propri titoli preferiti. La piattaforma offre un'esperienza interattiva e moderna per la community gaming, con un'interfaccia utente intuitiva.

## 🎯 Funzionalità Principali

- **🔍 Ricerca Giochi**: Cerca e scopri migliaia di videogiochi tramite integrazione con RAWG API
- **⭐ Sistema di Recensioni**: Crea e condividi recensioni dettagliate con valutazioni numeriche e stelle
- **👤 Profili Utente**: Personalizza il tuo profilo con un limite di upload delle immagini di 10mb e visualizza le recensioni di altri utenti
- **🔐 Autenticazione Sicura**: Sistema di login e registrazione con JWT
- **📱 Interfaccia Moderna**: Design responsive con animazioni

---

## ⚠️ Stato del Progetto

**ScoreBTW è attualmente in versione BETA.**

Questa versione include le funzionalità core della piattaforma. Il progetto è in fase di sviluppo attivo e sono previsti numerosi miglioramenti e nuove funzionalità in futuro.

## 📖 Description

**ScoreBTW** is a web platform dedicated to video game enthusiasts that allows them to discover, review, and share opinions on their favorite titles. The platform offers an interactive and modern experience for the gaming community, with an intuitive user interface.

## 🎯 Key Features

- **🔍 Game Search**: Search and discover thousands of video games through RAWG API integration
- **⭐ Review System**: Create and share detailed reviews with numerical ratings and stars
- **👤 User Profiles**: Customize your profile with a 10MB image upload limit and view other users' reviews
- **🔐 Secure Authentication**: Login and registration system with JWT
- **📱 Modern Interface**: Responsive design with animations

---

## ⚠️ Project Status

**ScoreBTW is currently in BETA.**

This release includes the core features of the platform. The project is under active development, and numerous improvements and new features are planned for the future.
